### 🎯 Главная идея версии 0.2.0

Мы превращаем движок из изолированного Re-Act симулятора в **автономного исследовательского агента (Autonomous Knowledge Discovery Agent)**.

Система работает на **Apple Silicon (MacBook M-series)** и использует **двухуровневую модельную схему**, чтобы не перегружать оперативную память (RAM/Unified Memory):

1. **Локальный 1.5B Роутер (`qwen2.5-coder:1.5b`):** Быстрый оператор (~100мс отклик). Ведет диалог с внешними ИИ, формулирует поисковые запросы, оценивает релевантность и управляет циклом сбора данных.
2. **Локальный 7B Архитектор (`qwen2.5-coder:7b`):** Глубокая аналитическая модель. Декомпозирует задачи на CS-абстракции, строит строго валидированные Trade-off матрицы и делает финальный Unraveling (детальный разбор).

---

### 🔑 Ключевые компоненты и сервисы

1. **Agent-to-AI Re-Act Dialogue Engine:**
* Локальная 1.5B модель ведет **активный многошаговый диалог (до 3 реплик)** с внешними ИИ (Gemini, Consensus AI, Perplexity) через Playwright или API.
* Она не просто запрашивает текст, а требовательно вытягивает первоисточники, прямые ссылки, замеры производительности и точки отказа (Failure Modes).


2. **Unified Search & Playwright Engine:**
* Унифицированный интерфейс для ArXiv API, Semantic Scholar API, DuckDuckGo и прямого парсинга через Playwright (Google / Google Scholar / блоги / Хабр).
* **Persistent Browser Context:** Хранение кук и авторизованных сессий на диске (`.browser_state/`). Однократная авторизация в окне $\rightarrow$ фоновая работа с защитой от разлогина (`check_session_alive()`) и эмуляцией человеческих задержек против капчи.


3. **Мультимодальный обработчик схем (Vision Pipeline):**
* Извлечение архитектурных диаграмм, графиков и топологий из найденных материалов.
* Делается кроп/скриншот элемента, который отправляется через Playwright в диалоговый Vision-интерфейс (или API) с получением текстового описания узлов, потоков данных и узких мест.


4. **Персонализированное сжатие (Profile-Guided Summarization):**
* Создается `user_profile.md` (содержит: *Backend/Fullstack, HighLoad, Python, Apple Silicon, Graph systems, Trade-off & Failure mode focus*).
* Все найденные документы сжимаются не "вообще", а с жестким фокусом на твои инженерные интересы.


5. **Локальная векторная база (Embedded RAG via LanceDB):**
* Векторная БД **LanceDB** работает прямо из файла в `knowledge_engine/.lancedb/` (0% фоновой нагрузки на RAM).
* Индексируются **только сжатые Executive Summaries**, а не сырой мусор. На каждом новом прогоне 1.5B модель сначала проверяет LanceDB, экономя время и интернет-трафик.


6. **Прозрачность работы (CLI Token Streaming & Thought Chain):**
* Потоковый вывод токенов от LLM в реальном времени.
* Отображение всех действий агента через `rich.live.Live` (например: `[Dialogue: Gemini] -> [Asking for ArXiv links...] -> [Parsing diagrams via Playwright] -> [Indexing LanceDB]`).
