## Личные данные и стек

- **Роль:** Middle Fullstack / Backend Developer
- **Основной стек:** Python, Node.js, PHP, JS/TS, REST API, Async/Event-Driven архитектуры, Микросервисы, Docker, LLM.
- **Бэкграунд и опыт:**
  - Практический опыт и профильное обучение на платформе **Yandex Practicum** по курсу Middle Python-разработчик.
  - Разработка сложной бизнес-логики: веб-платформы с интеграцией Moodle/WordPress, автоматической генерацией документов/сертификатов с ролевой моделью и тестированием.
  - Разработка динамических алгоритмов ценообразования для e-commerce (интеграция с Kaspi, автокоррекция цен по плавающему курсу USD без потери маржи).

## Аппаратное окружение (Hardware Ecosystem)

- **Рабочая станция:** Apple Silicon (MacBook M-series, Unified Memory).
- **Инфраструктурное ограничение:** Локальный запуск ИИ/LLM ограничен рамками Unified Memory на Mac. Приоритет — квантованные мелкие модели (1.5B–7B), экономия RAM, отсутствие фоновых «прожорливых» процессов (например, использование встраиваемой LanceDB вместо тяжелых векторных БД).

## Проекты в разработке

- **Джарвис (Jarvis):** Автономный локальный персональный помощник для управления вниманием, координации рабочих процессов и контекста на базе локальных LLM и Apple hardware.
- **Knowledge Engine:** Автономный исследовательский агент (Multi-agent Graph, GraphRAG, Re-Act диалоги, мультимодальный анализ архитектурных схем).

## Ключевые интересы и инженерный фокус

- **Advanced AI Architectures:** Мультиагентные системы (LangGraph), локальный деплой LLM (Ollama), оптимизация структуры данных для агентов, GraphRAG, механизмы роутинга и управление графом контекста (вытеснение/сжатие).
- **Системная инженерия:** Архитектура распределённых систем, Cache Invalidation, Event Sourcing, высоконагруженные системы (отслеживание трендов HighLoad++, Yandex events).

## Критерии отбора решений (Knowledge Engine Rules)

Любая аналитика, сжатие материалов (`DocumentSummary`) и Trade-off матрицы ДОЛЖНЫ строго проходить через эти фильтры:

1. **Trade-offs & No Magic:** Явные плюсы/минусы. Отсутствие абстрактных маркетинговых обещаний («работает из коробки»).
2. **Failure Modes & Edge Cases:** Обязательный разбор точек отказа: деградация, split-brain, stale reads, OOM, tail latency, проблемы при рассинхронизации данных.
3. **Operational Cost & Mac Suitability:** Оценка нагрузки на CPU/Unified Memory Apple Silicon, простота отладки, минимальный оверхед при локальной разработке.
4. **Fullstack Pragmatism:** Ориентация на сквозную реализацию — от структур данных и бэкенда до удобства интеграции с клиентской частью.
